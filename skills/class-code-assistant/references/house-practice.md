# Linden Shore Mutual premium audit house practice

The written rules are the classification guide excerpt (paragraphs `CG-nn`), which is the authoritative version of the
rules (interview 1, 08:41 PM). This file records the audit team's unwritten house practice as Nadia Brennan, Senior
Premium Auditor, stated it:

- interview 1: `interviews/ch03-premium-audit-20261027-0049.md`, cited as I1
- interview 2: `interviews/ch03-premium-audit-20261027-0157.md`, cited as I2

The `HP-n` labels are this Skill's own labels for traceability, not company identifiers. They never go in the
`rationale_ref` column, which takes only the guide's `CG-nn` identifiers. The guide itself says a class code is cited by
the paragraph that describes it.

This file has three parts, and they are kept apart on purpose:

1. **Confirmed rules**: what Nadia stated. Applied as rules.
2. **Stated gaps**: where Nadia said she has no rule or practice. Never filled in as if they were company rules.
3. **Readings**: this Skill's own interpretation where an answer leaves a detail open. Each one is raised as an open
   item wherever it affects an allocation.

## 1. Confirmed rules

| Label | Rule | Source |
|---|---|---|
| HP-1 | Classify people by what they actually do, not by job titles or application estimates. | I1 08:43 PM; I2 09:52 PM, 09:54 PM |
| HP-2 | One person's pay is not split between codes. The only exception is an inside employee (for example a dispatcher) who rides on delivery routes. If they ride on **two or more days in the same Monday-to-Sunday pay week**, that whole week's pay is driver payroll under T-610. A week with only one ride day stays under the employee's own code (C-110 for a dispatcher) in full, the same as a week with no ride. | I1 08:44 PM; I2 09:49 PM, 09:50 PM |
| HP-3 | A working owner who does any field work is counted at a flat **USD 63,700** of payroll under the employer's trade code, regardless of actual wages or what the owner drew. An owner who never works in the field is counted under C-110. | I1 08:44 PM; I2 09:50 PM, 09:51 PM |
| HP-4 | Clerical staff are C-110 unless they are on a job site **five or more days**. Days are counted across the entire audit period from the **site sign-in log**. A clerical person who reaches five days has their **whole payroll moved to the employer's governing code: the field code carrying the most payroll at that employer**. | I1 08:44 PM; I2 09:48 PM |
| HP-5 | Payments to uninsured subcontractors are added to payroll at **60%** of the amount paid, under the code for the work. A certificate of insurance counts only if it covers **the whole audit period** during which the work was performed. | I1 08:44 PM; I2 09:51 PM |
| HP-6 | Daily out-of-town allowances are left out of payroll up to **USD 47 per worker per day**. Any amount above that daily limit is payroll under that worker's code. | I1 08:44 PM; I2 09:52 PM |

| HP-10 | A case house practice does not cover: propose a treatment, write down why, and mark it as an open item for the employer to confirm. The auditor reviews the proposals. | I1 08:43 PM, 08:46 PM, 08:47 PM; I2 09:51 PM, 09:56 PM |

## 3. Readings (the Skill's interpretation; always raised as an open item where they matter)

- **R2 (crew timesheets, HP-2 and HP-13).** A crew member with more than one kind of work recorded is reported wholly
  under the code with the **most recorded days**. A tie is an open item.
- **R4 (governing code, HP-4).** The governing code is computed from employees' payroll under codes other than C-110,
  before any clerical person is moved, after the caterer receipts test, and without subcontractor additions. If counting
  subcontractor additions would pick a different code, that is raised as an open item. If the employer has no field
  code at all, the rule cannot apply: the person stays C-110 and an open item is raised.
- **R3 (owner's trade code, HP-3).** The worksheet names the owner's trade code from the records. If it differs from
  the governing code, that is raised as an open item.
- **R6 (allowance with no travel days).** With no recorded travel days, nothing qualifies for the USD 47 per-day
  exclusion (HP-6 as it stands), so the whole allowance is payroll under the worker's code.
- **R14 (receipts period).** The receipts test (HP-14) uses every month in the receipts record that overlaps the audit
  period. When the months do not line up exactly with the audit period, the report says so and shows the share.
