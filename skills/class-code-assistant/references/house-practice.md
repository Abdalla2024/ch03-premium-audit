# Linden Shore Mutual premium audit house practice

The written rules are the classification guide excerpt (paragraphs `CG-nn`). The guide is the authoritative version of
the rules (interview 1, 08:41 PM). This file records the audit team's unwritten house practice exactly as Nadia Brennan,
Senior Premium Auditor, stated it in interview 1 (`interviews/ch03-premium-audit-20261027-0049.md`).

The `HP-n` labels are this Skill's own labels for traceability. They are **not** company identifiers. Never put them in
the `rationale_ref` column, which takes only the guide's own `CG-nn` identifiers.

Where house practice and the guide differ, house practice is how this team applies the guide, and the report says so.
When a case is not covered here, there is no rule. Do not write one up as if it were the team's. Propose a treatment,
say why, and mark it as an open item for the auditor (08:43 PM).

## Stated gaps (no rule exists, so every such case is an open item)

- Supervisors and temporary workers: "I have no specific rules" (08:44 PM).
- Overtime, bonuses, tips and other payroll components beyond the out-of-town allowance: nothing was stated. CG-03
  (gross remuneration, including bonuses) applies.

## How this Skill reads the practice (assumptions, each flagged in every report where it matters)

These readings are the Skill's interpretation, not the auditor's words. Each one is surfaced as an open item wherever it
changes an allocation.

- **A1 (HP-2 "by whole weeks").** A pay week in which the inside employee appears as a ride-along on at least one route
  day goes entirely to the route code. Every other week stays under the employee's own code.
- **A2 (HP-2, no split elsewhere).** When crew timesheets record more than one type of work for one person, the whole
  of that person's pay goes to the code with the most recorded hours. A tie is an open item. CG-07 would permit a
  division. House practice says not to, and the report shows the margin.
- **A3 (HP-4 "five or more days").** Counted as distinct dates in the audit period on which the employee signed in at a
  job site (site sign-in log) or worked a crew timesheet. The code that replaces C-110 is the code of the work done at
  the sites visited most. The guide and house practice do not say which code it is, so this is always an open item.
- **A4 (HP-3).** The flat amount applies to an owner who is included under CG-05, meaning no election of exclusion is on
  file. It is counted under the code for the field work the owner does (CG-05), whatever the register shows as paid.
- **A5 (HP-5).** A subcontractor is treated as insured for a payment only when a certificate in the file covers the
  payment date. When a certificate's name differs from the payee name, the match is an open item.
- **A6 (HP-6).** The cap is USD 47 times the travel days recorded for that worker. An allowance paid with no recorded
  travel days is payroll in full.
